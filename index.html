ICS / iCalendar Cheat Sheet

One page on the .ics format Google Calendar, Apple Calendar and Outlook all speak — VEVENT fields, RRULE basics, time zones, and the import quirks that actually bite.

Minimal valid event

BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Example//EN
CALSCALE:GREGORIAN
BEGIN:VEVENT
UID:shift-42@example.com
DTSTAMP:20261021T000000Z
DTSTART:20261022T090000
DTEND:20261022T170000
SUMMARY:Day shift
LOCATION:Warehouse A
END:VEVENT
END:VCALENDAR

UID must be unique per event. DTSTAMP is when the file was written (UTC with a trailing Z). Without VERSION:2.0 and a wrapping VCALENDAR, many importers refuse the file.

Fields that survive every importer

FieldMeaningGotcha
SUMMARYTitleEscape commas as \,
DTSTART / DTENDStart / endAll-day events use date-only: DTSTART;VALUE=DATE:20261022
UIDStable idReuse the same UID to update an event; change it and you get a duplicate
DESCRIPTIONBody textNewlines as \n; keep it under a few KB
LOCATIONPlacePlain text — no nested address structure
RRULERecurrenceSee below; test in the target calendar before bulk import

RRULE in one screen

NeedExample
Every weekdayRRULE:FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR
Every 2 weeks on MondayRRULE:FREQ=WEEKLY;INTERVAL=2;BYDAY=MO
Monthly on the 1stRRULE:FREQ=MONTHLY;BYMONTHDAY=1
Stop after 10 timesadd ;COUNT=10
Stop on a dateadd ;UNTIL=20261231T235959Z

Pair RRULE with a floating or TZID-tagged DTSTART. A UTC Z start plus a weekly rule can drift for users in other zones.

Time zones

  • Floating local: DTSTART:20261022T090000 — means “9:00 in whatever zone the calendar uses.” Fine for personal schedules.
  • Named zone: DTSTART;TZID=America/New_York:20261022T090000 — preferred for shared calendars. Include a VTIMEZONE block if you want maximum Outlook compatibility.
  • UTC: DTSTART:20261022T130000Z — unambiguous, but night-shift people hate reading Zulu in the UI.

Import quirks worth knowing

  • Google Calendar: Settings → Import. US-style CSV dates (03/04) are ambiguous; prefer ISO in any CSV→ICS path. RRULE support is good; custom EXDATE lists occasionally drop.
  • Apple Calendar: double-click or Mail attachment. All-day events that include a time component show as overnight blocks — use VALUE=DATE.
  • Outlook: File → Open & Export → Import/Export. Some builds ignore VALARM; classic Outlook is pickier about missing UID.
  • Line folding: RFC 5545 folds lines at 75 octets. A hand-edited file with one giant DESCRIPTION line can fail parsers that enforce the limit.
